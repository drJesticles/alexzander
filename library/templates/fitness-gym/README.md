# Fitness Gym
Six-page template for a coached gym: classes, three-tier memberships with comparison table, trainers, weekly schedule tables, join page. Default kit: aaa-hs-bold.
Copy is written for a fictional no-contract gym in Russellville, AR; swap classes, coaches, prices and times in place. The schedule page uses a one-off wrapper section (t-fitness-gym-schedule) around two el-table-striped blocks.
