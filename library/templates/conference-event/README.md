# Conference
Six pages for a small developer conference: Home (hero, countdown to data-wf-date, sponsor logos, why-come grid), Speakers (team-grid), Schedule (content-tabs plus a striped session table), Tickets (three tiers plus FAQ), Venue (map plus travel cards), Register (form).
Default kit fluent2; business.name is the event name and business.address the venue, both in site.json.
