# Paper / Newsprint
Off-white #f7f4ea stock with a faint halftone dot pattern, #1a1a1a ink, #8b0000 for accents and link underlines. Playfair Display 900 mastheads, Libre Baskerville body.
Double rules on h1, hr and card tops; underline-only inputs; italic lead with an enlarged red initial. No radii, no shadows, no dark scheme (newsprint is light).
