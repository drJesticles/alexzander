# Radix Themes

Source: https://www.radix-ui.com/colors (indigo, slate, green/amber/red/blue step 11 for text) and Radix Themes' button/card variants.
Approximated: `--wf-secondary` doubles as a soft indigo button via `--radix-accent-soft`; dark primary is indigo 10 (#5472E4) with white text (~4.3:1, matching Radix's own solid buttons). Alpha-based Radix shadows are flattened to rgba layers.
