# Material Design 3

Source: https://m3.material.io (baseline static color scheme, shape scale, type scale). Primary #6750A4, surface #FFFBFE, dark surface #141218 are the published baseline values.
Approximated: hover states use a darker/lighter primary instead of M3 state layers; surface tints are expressed as flat `--m3-*-container` colors; display type is Roboto 400 (Roboto Flex is not on Google Fonts in the same way).
