# Bootstrap 5

Source: https://getbootstrap.com/docs/5.3 (color system, `data-bs-theme="dark"` values, button/form sizing, shadow utilities).
Approximated: warning and info as *text* tokens use the 5.3 text-emphasis values (#997404 / #087990) because #ffc107 and #0dcaf0 fail body-text contrast. Dark mode promotes the link blue (#6ea8fe) to primary with dark text; Bootstrap itself keeps #0d6efd buttons in dark mode.
