# Apple HIG

Source: https://developer.apple.com/design/human-interface-guidelines (color, typography) and apple.com's public marketing CSS for the web feel.
Approximated: SF Pro is not loadable from Google Fonts, so the stack prefers the system SF fonts and falls back to Inter. Light-mode primary uses #0071E3 (apple.com's button/link blue, 4.7:1 on white) rather than #007AFF (4.0:1); dark mode uses #0A84FF as specified.
