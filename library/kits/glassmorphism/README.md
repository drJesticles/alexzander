# Glassmorphism
Body carries a fixed violet-to-cyan gradient (token --glass-grad, swapped per scheme). Cards, inputs, badges and buttons are translucent white with backdrop-filter blur, 1px translucent borders and a top highlight.
Violet #7c3aed primary, cyan accent, 20px radii, Poppins. Light scheme is pastel with dark ink; dark scheme is deep violet with light type.
