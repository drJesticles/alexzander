# DaisyUI (cupcake / dracula)

Source: https://daisyui.com/docs/themes/ — the `cupcake` theme (base #faf7f5, primary #65c3c8, secondary #ef9fbc, accent #eeaf3a, rounded-btn 1.9rem, rounded-box 1rem) and the `dracula` theme for dark.
Approximated: DaisyUI's oklch values are rounded to hex; links and eyebrows use a darker teal (`--daisy-link`, #1f7a80) because pastel teal on cream is ~1.9:1; `.wf-section--dark` becomes a pink "secondary" band in light mode, which is the cupcake look rather than a true dark band.
