# Chakra UI

Source: https://v2.chakra-ui.com (default theme colors teal/gray/purple, button sizes, shadows, `outline` focus token blue.500).
Approximated: `--wf-primary` keeps teal.500 (#319795) for fills as specified (white-on-teal is ~3.5:1, same as Chakra's own solid teal button); inline links and eyebrows use teal.600 via `--chakra-link` so running text stays above 4.5:1. Dark mode uses teal.300 with gray.800 text the way Chakra's dark color-mode does.
