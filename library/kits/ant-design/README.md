# Ant Design

Source: https://ant.design/docs/spec/colors and the antd v5 default/dark algorithm tokens (colorPrimary #1677ff, borderRadius 6, controlHeight 32, line-height 1.5714).
Approximated: alpha neutral tokens (rgba(0,0,0,.88) etc.) are flattened to hex; success/warning/danger use the step-7 "text" shades so they read as text; dark primary uses antd's dark primary-5 (#3c89e8) instead of #1668dc for link contrast.
