# Tailwind / shadcn/ui

Source: https://ui.shadcn.com/themes (default "zinc" theme, radius 0.5rem) and Tailwind's zinc palette and shadow scale.
Approximated: shadcn's `accent` is a hover gray, so `--wf-accent` is zinc-200 (light) / zinc-700 (dark) rather than a hue; destructive uses red-600 instead of red-500 for 4.5:1 text contrast.
