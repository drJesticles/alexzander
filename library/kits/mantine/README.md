# Mantine

Source: https://mantine.dev/theming/colors/ (blue/gray/dark color arrays), default theme (radius md 8px, button height 36px, shadow xs/md/lg).
Approximated: "dimmed" text uses gray.7 (#495057) instead of gray.6 for 4.5:1; dark mode uses blue.5 (#339af0) with dark label text for primary instead of blue.8 + white, so links and button labels stay readable on dark.7.
